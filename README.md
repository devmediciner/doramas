# Catálogo de Doramas

Interface web moderna para visualização, busca e reprodução do catálogo completo de doramas.

## 🚀 Funcionalidades
- **Mais de 4.000 títulos** catalogados.
- **Busca em tempo real:** filtre instantaneamente por título ou gênero.
- **Infinite Scroll:** navegação fluida e rápida.
- **Player integrado:** modal com reprodução direta e informações da obra (sinopse, capas e tags).
- **Compatível com GitHub Pages:** pode ser acessado diretamente pelo navegador sem necessidade de backend.

## 📁 Estrutura de Arquivos
- `index.html`: Interface visual responsiva em tema escuro.
- `doramas.json`: Dados completos do catálogo estruturados em JSON.
- `doramas_data.js`: Base de dados em JavaScript para execução local e web sem restrições de CORS.
