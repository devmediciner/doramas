# 🍿 LoiraFlix - Catálogo de Doramas

Interface web moderna para visualização, busca e reprodução do catálogo completo de doramas.

## 🚀 Funcionalidades
- **Conexão ao Vivo com o Supabase** e fallback offline automático.
- **Seções Estilo Streaming:**
  - 🆕 Novos Lançamentos
  - 🔥 Mais Assistidos
  - ⭐ Destaques
  - 🎙️ Dublados em Português
  - 💕 Romance, ⚔️ Ação, 💔 Traição & Vingança, 👑 Histórico, 💎 Riqueza.
- **Hero Banner:** Destaque rotativo com sinopse e botão de play.
- **Busca em tempo real:** filtre instantaneamente por título, gênero ou sinopse.
- **Player integrado:** modal com reprodução direta e informações da obra.
- **Compatível com GitHub Pages:** pode ser acessado diretamente pelo navegador.

## 📁 Estrutura de Arquivos
- `index.html` / `catalogo.html`: Interface visual responsiva em tema escuro.
- `doramas.json`: Dados completos do catálogo estruturados em JSON.
- `doramas_data.js`: Base de dados em JavaScript para execução local e web sem restrições de CORS.
